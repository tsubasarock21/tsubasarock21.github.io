画像から機体を作る手順
1. 保存枠を選ぶ → デザイン → 「画像から機体をつくる」。
2. 写真・画像を選択。指で画像を動かし、拡大スライダーで切り抜く範囲を調整。
3. 「ドット絵に変換」。中央のコアを見ながら指で位置を動かし、大きさを調整。
4. 必要に応じて背景色の除去を調整。透明PNGの透明部分はそのまま空白になります。
5. 「この機体に反映」で選択枠に保存。ペン・消しゴムで仕上げられます。

背景除去は色を基準とした処理です。複雑な背景の写真は完全に切り抜けない場合があります。
取り込んだインクが100を超える場合は機体を縮小してください。初期サイズは上限に収まるよう自動調整します。
画像は端末内で処理します。アップロード・外部AIへの送信はしません。ファイルは30MB以下、JPEG・PNG・WebPなどブラウザーが読める形式を使用してください。
反映前の機体は保持され、反映後も「ひとつ戻す」で戻せます。

3機の保存・色・ドットサイズ・スタンプ・拡大縮小・消しゴム・戻す／やり直す・既存の戦闘・広告・アクセス計測を維持。
機体は同じ端末・ブラウザー内に保存されます。別ブラウザー、試運転版と公開版など保存領域が異なる環境では共有されません。

初回から遊べる3機
機体1：バランス型（ミント）／装甲と機動性を両立。
機体2：速度型（青）／軽量で移動・弾速を優先。
機体3：攻撃型（オレンジ）／短い砲口までの経路で連射を優先。
保存済みの機体を上書きしません。旧版の空き枠は初回だけ補充します。自分で枠を消した場合、次回起動時に勝手に復活しません。編集画面のサンプルボタンで対応する機体を戻せます。

今回の追加
・デザイン画面で3枠それぞれに機体名を付けられます（24文字まで）。既存機体を保持します。
・全ユーザー共通ランキング。結果画面で登録ボタンを押した記録だけを送信します。
・ホームの「みんなのランキング」で上位20機の機体名、スコア、周回、雑魚撃破率、縦横モードを表示。
・同じ端末・ブラウザーの同じ保存枠では最高スコアだけを保持。名前・デザインを変えても同じ枠です。
・ログイン不要。別端末やブラウザーには引き継げません。端末の保存データを消すと別の利用者扱いになります。
・公開版のみ登録可能。試運転からの登録は無効です。閲覧は試運転からも可能です。
・共通ランキングには別ZIP「lab-rank-v104.zip」のサーバーファイル設置が必要です。
・ボスの突撃は画面の上下方向のみ。突撃・復帰中の横位置は固定です。
・雑魚撃破率を戦闘中と結果に表示。撃破した雑魚÷出現した全雑魚で計算し、見逃し・撤退・残存も分母に含めます。ボスは別集計です。
・被弾時の仕様は変更なし。残り装甲・砲口・発射間隔は変化します。移動速度・弾速・一発の威力は出撃時固定です。連射が速まると秒間火力は上がる場合があります。

登録した機体名・記録は公開されます。本名などの個人情報は入力しないでください。
ブラウザー内の計算結果を送るため、数値整合性の確認はありますが完全な不正防止ではありません。

機体名の入力は任意。空欄・空白のみの場合は「名無し」としてホーム・結果・ランキング・シェアに表示します。名前が同じでも別端末・別枠の記録は統合しません。サーバーファイルはlab-rank-v104.zipのままで対応します。

ランキングには登録日時（日本時間）と記録時のゲームバージョンを表示。難易度設定がないインクストライクでは難易度を記録・表示しません。

機体画像付きランキング
出撃時のデザインを64×64のPNGとして記録と一緒に登録します。画像は登録ボタンを押したときだけ送信され、元の写真や描画データ全体は送りません。
後から機体を描き直しても、すでに登録した画像は変わりません。ベスト更新時にその出撃時の画像へ更新します。
画像なしの過去記録は維持します。ゲームだけでなくlab-rank-v104.zip側の更新も必要です。

v0.4.4 自動ランキング
公開版で、各保存枠のベストを更新したときは操作なしで記録を登録します。成功時は結果上部へ「○位にランクイン！」を表示します。上位20位圏外はベスト登録完了、失敗時は再試行ボタンを表示します。
初回の記録も登録対象。同点・低い点では自動登録しません。試運転は自動登録しません。
名前・画像・記録の公開についてホームと結果に明記しています。ランキング機能には lab-rank-v104.zip の追加・更新が必要です。
